## 3. 人工确认过的方法

- 用新版 timestamp 对齐结果，当前为 offset0。
- 任意相机缺帧则该 trigger 整帧跳过。
- 外部双目 2D 先滤波，再三角化。
- 过滤不能太强，弱滤波版更贴近动作。
- 头部投影使用 `xy_swap + z_flip`。
- 头部投影必须使用 omni/fisheye 模型。
- 鼻子 2D 和 CH07 推算的鼻子 3D 可作为深度/位置校准参考。
- 优化对象是 3D 骨架，不是 2D 检测点。
- 头部双目手动 2D GT 可反投影成另一套 3D GT，与外部 3D 做加权拟合。

## 4. 需要避免的历史结果

- `+77` offset 视觉扫描结果。
- 旧 `+71` 关系在新版对齐中的继续使用。
- 旧坐标映射下的 CH07 结果。
- 未区分 strict/event 和 source_time 的视频速度判断。
- 使用 tag 中心直接当 wrist。
- 把多 tag 位姿优化当作每帧最稳结果。
- 用普通 pinhole 投影头部鱼眼图像。

## 5. 仍需人工审核的问题

1. `head_stereo_fullbody_2d_gt.csv` 只有 4 个 sequence，其中 5-15s 内只有 252 和 302 两帧，作为拟合 GT 样本偏少。
2. 头部双目反投影 ray miss median 26.40 mm，p90 58.15 mm，说明手动点、鱼眼内参或 head 外参仍可能有误差。
3. 当前手动 GT 拟合对高权重点有效，但低权重点误差仍大。
4. 脚尖在外部 RTMPose 中没有直接对应 joint，目前用脚部局部向量外推，必须人工确认是否合理。
5. 这组数据外部触发线丢帧严重，全量视频的信息完整性不足。
6. 如果后续继续使用骨长约束，应确认头部反投影骨长和实测骨长哪个更可信。
